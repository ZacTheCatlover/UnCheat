# UnCheat

## Supported Mods
* [Civ V - Gods & Kings](https://github.com/yairm210/Unciv/tree/master/android/assets/jsons/Civ%20V%20-%20Gods%20%26%20Kings)
* [RekMOD](https://github.com/ravignir/RekMOD)
* [DeCiv Redux](https://github.com/SpacedOutChicken/DeCiv-Redux)
* [Alpha Frontier](https://github.com/carriontrooper/Alpha-Frontier)

## Features Overview
### City Passives
Buildings that only affect the city they are built in.

| Building | Effects | Note |
|:---:|:---:|:---:|
| [Stat] | Select the percentage of the yield boost for [Stat] from -500% to +5,000% | |
| No Unhappiness | -100% Unhappiness from Population in this city | |
| Max XP | New All units start with 1,000,000 XP in this city | |
| Max Promotions | All newly-trained units in this city receive All promotions | |
| Fast Building | 1,000% Production when constructing All buildings, units, and wonders in this city | |
| Auto Buildings | Gain all available buildings in this city for free | |
| Auto Wonders | Gain all available wonders in this city for free | |
| Freeze Growth | Nullifies Growth in this city | |
| Freeze Border | 1,000,000,000% Culture cost of natural border growth in this city | |

| Max Promotions+ | All newly-trained units in all cities receive All promotions | |
| Max Spies | New spies start with 2 levels | |
| Inf. Supply | 1,000 Unit Supply | |
| Free Purchase | -100% Production, Food, Gold, Science, Culture, and Faith cost of purchasing items in cities | |
| No Maintenance | -100% maintenance costs for All buildings, units, improvements, roads, and railroads | |
| Fast Improvement | -100% construction time for All improvements | |
| Fast Building+ | 1,000% Production when constructing All buildings, units, and wonders in all cities | |
| Auto Buildings+ | Gain all available buildings in all cities for free | |
| Freeze Growth+ | Nullifies Growth in all cities | |

| Freeze Border+ | 1,000,000,000% Culture cost of natural border growth in all cities | |
| Forever Influence | -100% City-State Influence degradation | |
